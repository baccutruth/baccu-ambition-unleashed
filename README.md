# BACCU™ Ambition Unleashed

A lightweight, mobile-first South African youth opportunity and practical-skills platform.

**Core message:** Your next opportunity starts here.  
**Discover. Learn. Create. Connect.**

## First version

- Opportunity Hub with clearly labelled demonstration pathways.
- Daily Wisdom & AI Toolkit with copy-ready prompts.
- Civic & Youth Connect with official public-sector resource links.
- About BACCU and contact route.
- Responsive, accessible navigation and search/filter controls.
- PWA manifest and service-worker offline shell.
- No login, tracking, API keys or paid backend services.

## Run locally

Serve this folder with any static HTTP server. The service worker requires localhost or HTTPS. The app uses plain HTML, CSS and JavaScript.

## Trust standard

Demonstration cards are not vacancies or open applications. Do not publish a live opportunity unless the provider, opportunity type, eligibility, location, application status, official deadline (if stated), requirements, official application URL and last verified date have been checked against an authoritative source.

BACCU shares information for educational purposes. Opportunities remain subject to provider requirements, eligibility and selection decisions. BACCU does not guarantee employment, funding or earnings.

External links are resource references only. They do not imply a partnership or endorsement.
